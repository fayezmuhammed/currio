# Currio

**Select. Convert. Done.**

A Chrome extension that converts prices on any webpage. Highlight a price like `AED 850` or `$1,299.99` and Currio shows it in your currency.

## Install

```bash
npm install
npm run build
```

Then open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the `dist/` folder.

## Privacy

No tracking, and no page content leaves your browser. See [PRIVACY.md](PRIVACY.md).
